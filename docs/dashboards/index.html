WebTools

Kotlin/JVM internet I/O helpers, published as three independent single-concern artifacts: webtools-udp for multi-client UDP connections, webtools-scraping for reading URLs, webtools-browser for headless-Chrome screenshots. Issue #55 plans an HTTP client stack beside them; it is drawn dashed and is not built.
