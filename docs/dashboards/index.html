SpartanLaboratories/WebTools

WebTools

Kotlin internet I/O helpers, published as independent single-concern artifacts — webtools-udp for multi-client UDP connections, webtools-scraping for reading URLs, webtools-browser for headless-Chrome screenshots, and webtools-http, the common core of a suspend HTTP stack with its outbound-URL policies and its published test fixtures, new and not released yet — built, tested and published by one Gradle build. The rest of the HTTP stack and a feeds module are planned, drawn dashed.

Guarantees

  

    
Failure model

      

        
udpkotlin.Result; typed: HandshakeRefusedException, IncompatibleProtocolException, ReliableWindowFullException, ReliableMessageTooLargeException. Retries a reliable message until acked; handshake() times out (4 s by default) and the caller retries. A throwing onClientConnect kills mcups-listener.

        
scrapingkotlin.Result from every call but hasNext() (a Boolean, false on failure): MalformedURLException, IOException, EOFException, IllegalArgumentException (nothing open), InterruptedException. Nothing retried.

        
browserkotlin.Result: a blank URL, a driver launch, a navigation or a decode failure all come back as a failure. Nothing retried.

        
buildA failing compile or test fails ./gradlew build. The seven level tasks are not wired into check and pass on an empty selection; build-logic's own test tasks fail on one. verifyJavaFloor, in every module's check, fails on a class above Java 11 bytecode or a variant declaring another JVM version; fixturesPublicationCheck, in webtools-http's, on a change to its published test fixtures.

        
httpkotlin.Result: Url.parse and HttpMethod.of fail with an IllegalArgumentException of constant text; a port returns an HttpFailure (TransportFailure, UpstreamFailure, Closed). A broken developer-written value throws at construction; cancellation is thrown. Nothing retried: one request per hop. Its test fixtures: the fake returns its scripted Result and throws UnmatchedRequestError for an unmatched request; a malformed fixture throws FixtureError; the recorder never fails a call. Its URL policy: a broken policy or settings value throws IllegalArgumentException when its block ends; CidrBlock.parse returns a failure.

Thread safety

      

        
udpAny thread: the server's sends; the client's send, keepalive and probe start/stop, and stop(). handshake() once, before start. admit and onClientConnect run on mcups-listener, handlers on the dispatch thread.

        
scrapingKDoc: shareable, but serialises callers. open() is @Synchronized and waits while another connection is open; next() and close() are not synchronised.

        
browserHolds one immutable setting; each call launches its own driver and Chrome. The KDoc states no thread contract.

        
buildwebtools-udp's four socket-binding test tasks share one build service (maxParallelUsages = 1); build-logic's three nested-build tasks share another, for the TestKit home.

        
httpValues, policies and settings are immutable and safe to share; HttpTransport.execute may be called concurrently and must be main-safe; a builder lives inside its factory's lambda. The fake and the recorder are safe to share; VirtualClock.advanceBy is for the test's thread.

        
feedsplanned — nothing built yet

      

    
Resources to close

      

        
udpServer stop() frees UDP 9998 and the mcups-* threads (single-use; skipped, the next server in the JVM cannot bind). Client stop(), idempotent. Connection.terminate() for a timed-out peer. All threads are daemons.

        
scrapingConnector.close(): skipped, the next open() waits forever. Not AutoCloseable. Each Connector() leaves a Unirest client and its daemon monitor thread behind; nothing closes them.

        
browserNothing to close: each capture quits its driver in finally. The screenshot PNG is deleted at JVM exit; each capture's webviewer-chromedriver*.log temp file is never deleted.

        
buildnothing a consumer holds; the TestKit home (about 910 MB) stays between runs until clean

        
httpHttpTransport is AutoCloseable: close() is idempotent and never throws, the fixtures' fake and the recorder's wrapper included. No network transport ships in 1.0.0; no other type holds a resource.

Process-wide effects

      

        
udpA server binds the fixed UDP port 9998: one server per host at a time.

        
scrapingConnector() sets Unirest's process-wide timeouts to 0 (infinite) and rebuilds its clients; open() sets the JVM-wide http.agent property to a browser string.

        
browserEach capture starts chromedriver and Chrome, writes two temp files, and blocks the caller for pageSettleMillis.

        
buildnone at runtime

        
httpnone: no thread, socket or process-wide setting; the test fixtures' recorder writes files only behind its gate, never when a CI variable is set
