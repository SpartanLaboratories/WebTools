Timeline: gap, considered, verdict, as built

Decision log

Every option from every row, with its verdict and the reason. Declined options stay on record: they are what a later plan must argue against before reopening a question. An option deferred at plan time shows how column 4 settled it.

As built: what exists, and every change from the verdict

One card per row. Its state says how the built thing relates to the verdict; each change names what moved, why, and in which stage or review it was decided. The verdict column is never edited to match: this register is where the difference lives.

Chain: the units in landing order

Each unit is a sub-issue, planned and built at its own level on its own board. An arrow runs from a unit to the units it blocks; columns are the earliest a unit can start. Click a unit for its row.

plan.json the committed file, embedded verbatim

The page is built from this file at load. The presenter writes it at each event of the issue's run; plan/scripts/embed.js copies it in here and plan/scripts/check.js verifies the copy and the rules.
